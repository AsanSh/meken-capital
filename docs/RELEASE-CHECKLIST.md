# Приёмка meken.im

- [ ] Разместить сервер и постоянный диск; проверить Docker-сборку.
- [ ] Установить уникальный пароль администратора и production-origin.
- [ ] Направить DNS, проверить HTTPS и перенаправление www.
- [ ] Создать partner@meken.im; указать провайдера/страну хостинга в политике данных.
- [ ] Утвердить пользовательские и проектные документы оператором и профильными специалистами.
- [ ] Проверить регистрацию, повторный вход, заявку, допуск, выдачу PDF, голос, уведомление на публичном домене.
- [ ] Настроить резервное копирование вне сервера и проверить восстановление.

Не подключены: платежи, внешняя идентификация, автоматическая почта, электронная подпись, Planalytic API. Для запуска публичной платформы реальных инвестиций эти процессы должны быть определены отдельно. Передача исходников не является подтверждением регуляторной готовности.
