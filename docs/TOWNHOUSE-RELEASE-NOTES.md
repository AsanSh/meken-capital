## Реализовано

- Два паспорта в существующей оболочке: `/#project/besh-kungey`, `/#project/oskon-ordo`.
- Карточки реальных инициатив выделены над учебными примерами в маркетплейсе.
- Общая финансовая модель в `site/townhouses.js`: четыре варианта, два источника земли, дополнительные расходы, стресс и задержка.
- Формат валюты паспортов и заявок — USD независимо от переключателя валюты старого каталога.
- `POST /api/project-interests` сохраняет предварительный интерес. Одна актуальная запись на пользователя и объект; повторная заявка заменяет вариант и сумму, исключая двойной счёт альтернативных вариантов.
- `GET /api/project-interests` возвращает только собственные заявки; `GET /api/admin/project-interests` доступен только администратору.
- Таблицы интереса доступны в кабинете инвестора и админке. Реальные инвестиционные средства через этот модуль не принимаются.
- После входа пользователь возвращается в выбранный паспорт.
- Данные о действующем такафуле не выдуманы: обязательность заявлена организатором, статус документов показан отдельно.

## Проверки

21 автоматический тест прошёл; сборка и проверка diff прошли. Интеграционный тест PostgreSQL выполнен в отдельной случайной схеме, после завершения удалена только эта временная схема. Производственные инвесторы и договоры не создавались.

В браузере проверены паспорт Беш-Кунгея, переключение ПСО и финансирования только стройки (391 200 USD; результат 60 000 USD), паспорт Оскон Ордо на ширине 390 px, возврат к каталогу. Ширина документа 390 px совпадает с viewport, переполнения страницы нет. Консоль браузера не содержит ошибок на проверенных экранах. Элементы авторизованной подачи проверены API-тестом; полный сценарий с реальной учётной записью в production не выполнялся.
