# Публикация Meken на Vercel

Дата: 6 сентября 2026.

- Публичный адрес: https://meken-capital.vercel.app
- Проект: meken-capital, команда asans-projects-88edff6a.
- Вход администратора: https://meken-capital.vercel.app/#admin-login
- Администратор создан из приватного локального .env; пароль не включён в исходники.
- База: отдельный Neon meken-capital-db, free_v3, Франкфурт. Существующие проекты не изменялись.

## Проверено

16 локальных тестов. Отдельный интеграционный сценарий на PostgreSQL в изолированной временной схеме: регистрация, роли, публикация, заявка, допуск к PDF, голосование, смена пароля, сохранение после перезапуска.

На публичном адресе проверены HTTP 200 главной, CSS, изображений, health и курса НБКР. Вход администратора и выход работают; без сессии админский API возвращает 401, .env возвращает 404. Реальные предложения и тестовые инвесторы в рабочую базу не добавлены.

## Секреты и продолжение

Переменные Neon добавлены интеграцией. ADMIN_EMAIL/ADMIN_PASSWORD заданы в Vercel как sensitive. .env.vercel.production игнорируется Git, права 600. Не выводить его содержимое.

Публикация: vercel deploy --prod --yes. Проверка PostgreSQL: node --env-file=.env.vercel.production scripts/test-postgres.mjs. Скрипт создаёт и удаляет только свою случайную тестовую схему.

До реальных инвестиций отдельно нужны договоры и шариатская проверка, внешние KYC/AML, платежи/подпись при необходимости, рабочая почта, политика резервирования и проверка восстановления Neon. Наличие опубликованного сайта не означает готовность этих внешних процессов.
