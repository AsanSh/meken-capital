# Meken Capital — портал венчурного управляющего

Публичный сайт, макеты кабинета участника и техническое задание на портал
для привлечения квалифицированных инвесторов (в т.ч. диаспоры в США)
в сделки со стройкой, стройматериалами и строительными технологиями в Бишкеке
на исламских принципах.

| Папка | Что внутри |
|---|---|
| `site/` | Публичный статический сайт meken.capital (9 страниц, RU + EN). Кладётся на GitHub Pages / Cloudflare Pages как есть. |
| `mockups/` | HTML-макеты: предпросмотр всего сайта одной страницей, каталог сделок (за логином), кабинет участника. |
| `docs/TZ.md` | Техническое задание на портал: роли, модули, жизненный цикл сделки, модель данных, интеграции, этапы. |
| `docs/legal-architecture.md` | Правовая архитектура: закон о венчурном финансировании, закон об инвестфондах, исламские инструменты и как они стыкуются. |
| `docs/design-system.md` | Дизайн-система: палитра, типографика, компоненты, правила текстов. |

## Статус
- Публичный сайт: готов к публикации после замены иллюстративных цифр закрытых сделок на реальные и вписания номера реестра.
- Кабинет участника: макет. Разработка — после учётной регистрации управляющего в реестре.
- Формы на сайте: заглушки, бэкенд не подключён.

## Публикация сайта
1. Включить GitHub Pages для этого репозитория, папка `/site` (или скопировать её содержимое в отдельный репозиторий).
2. В DNS домена meken.capital: `A @ → 185.199.108.153 / .109.153 / .110.153 / .111.153`, `CNAME www → <login>.github.io`.
3. В Settings → Pages указать custom domain `meken.capital`, включить Enforce HTTPS.

Все суммы в проекте — только KGS и USD.
