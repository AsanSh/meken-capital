# Meken Capital — платформа сделок с реальными активами

Публичный сайт, интерактивный маркетплейс, макеты кабинета участника и документы для платформы ОсОО «Адвестор». Цель — отдельные сделки со стройкой, товарами, недвижимостью и инновационными компаниями в Бишкеке на принципах исламского финансирования. Правовой статус каждой сделки определяется до её открытия.

| Папка | Что внутри |
|---|---|
| `site/` | Единый портал meke.capital: маркетплейс, закрытый инвестклуб, оборотный капитал, админ-портал и правовые документы. |
| `mockups/` | HTML-макеты: предпросмотр всего сайта одной страницей, каталог сделок (за логином), кабинет участника. |
| `docs/TZ.md` | Техническое задание на портал: роли, модули, жизненный цикл сделки, модель данных, интеграции, этапы. |
| `docs/legal-architecture.md` | Правовая архитектура: закон о венчурном финансировании, закон об инвестфондах, исламские инструменты и как они стыкуются. |
| `docs/private-credit-strategy.md` | Критический разбор модели Planalytic + Meken Capital, рекомендуемая структура, риск-модель и roadmap на 5 лет. |
| `docs/design-system.md` | Дизайн-система: палитра, типографика, компоненты, правила текстов. |

## Локальный просмотр

```sh
python3 -m http.server 4173 --bind 127.0.0.1 --directory site
```

Откройте единый портал: http://127.0.0.1:4173/concepts/market.html. Сборка и установка пакетов не нужны.

## Статус

- Новая главная: графит / лайм, анимированное раскрытие города из чертежа, выбор месяца, график и метрики из единого набора демо-данных, просмотр и скачивание учебного отчёта. Это слоёная растровая анимация, не интерактивная 3D-модель.
- Все 9 страниц используют общую тёмную палитру. Полный новый сценарий главной реализован на русском; английская страница сохраняет прежнюю структуру.
- Кабинет участника: портфель, анкета подбора, Data Room, таймлайн капитала, KGS/USD, RU/EN, голосования, календарь и уведомления. Авторизация и данные пока локальные, тестовые — перед эксплуатацией нужен сервер.
- Админ-портал: очередь сделок, поиск и статусы, инвесторы/KYC, движение капитала, комплектность документов и блокировка публикации до заполнения пяти обязательных проверок. Данные текущей HTML-версии хранятся только в сессии браузера; перед эксплуатацией необходимы сервер, роли и авторизация.
- Форма приглашения проверяет поля и согласия, затем готовит письмо. Пользователь отправляет его из своей почты; сервер ничего не принимает. Результат скрывается после изменения данных или согласий.
- До публикации нужны подтверждённые реквизиты и показатели, проверка содержания владельцем и правовая проверка. Демо-данные не являются результатами деятельности.
- Все три продуктовых контура связаны постоянной навигацией и возвратом на единый портал.
- Актуальный портал находится в `site/`; конфигурация GitHub Pages должна публиковать эту папку.

## Проверка

```sh
node --test tests/site.test.mjs tests/platform-model.test.mjs
MEKEN_JSDOM_PATH=/absolute/path/to/jsdom node --test tests/platform-ui.cjs tests/admin-ui.cjs tests/investor-ui.cjs
```

Визуальная проверка: `design-qa.md`. Дизайн и происхождение ресурсов: `docs/design/implementation.md`. Исходный `docs/design-system.md` сохранён как историческое ТЗ; новый визуальный выбор описан отдельно.

## Публикация сайта

Основной домен в `CNAME` — `meke.capital`. Для публикации нужно настроить GitHub Pages или другой хостинг на содержимое `site/`, а затем проверить DNS и HTTPS.

Продолжение разработки другим агентом: [docs/HANDOFF.md](docs/HANDOFF.md).

Все суммы в проекте — только KGS и USD.
