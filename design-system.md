# Дизайн-система

## Идея
Спокойный, «бумажный» документ, а не финтех-витрина. Аудитория — люди, которые уже обожглись на обещаниях; интерфейс должен выглядеть как договор, которому верят, а не как реклама.

## Палитра
| Токен | Значение | Роль |
|---|---|---|
| `--bg` | #F8F4EC | фон страниц |
| `--paper` | #FFFFFF | карточки, формы, чередующиеся секции |
| `--ink` | #1F2A24 | основной текст |
| `--muted` | #66716B | вторичный текст |
| `--line` | #E3DCCD | границы |
| `--forest` | #1E4D3B | кнопки, положительные результаты |
| `--forest-deep` | #153629 | hero, финальные секции |
| `--gold` | #B8862E | главное действие, подписи разделов |
| `--sky` | #DCE9E2 | информационные блоки |
| отрицательный результат | #9A3E33 | только в таблицах |

Кабинет участника (тёмная тема): фон #101815, панели #172420 / #1E2E29, акценты #6FD3B0 (mint), #E4B45A (amber), #E77A6A (coral).

## Типографика
- Заголовки: Lora 500/600, курсив для второй части главного заголовка.
- Текст: Inter 400/500/600, 16px, межстрочный 1.6.
- Крупные фактические числа (результаты, ключевые показатели): Lora, 20–40px, цвет `--forest`.
- Никаких верхних регистров в подписях, никаких стрелок в кнопках.

## Компоненты
- Баннер статуса КИ — на каждой странице под шапкой.
- Карточка (`.card`): рамка `--line`, радиус 10px, без тени.
- Таблица закрытых сделок: результат в отдельной колонке серифом, убыток — красным, без выделения фоном.
- Форма: поля на #FCFAF6, чекбоксы согласий — обязательные, кнопка во всю ширину.
- Блок регистрации (`.reg`): фон `--sky`, список определений.
- Факты (`.facts`): золотая левая линия, число серифом над пояснением.

## Правила текстов
- «Целевая» и «расчёт управляющего» — только за логином; публично — «результат».
- Глаголы действия в кнопках: «Запросить приглашение», «Получить код входа».
- Каждая доходность в кабинете сопровождается пометкой «не гарантия».
- Валюты — только KGS и USD.
